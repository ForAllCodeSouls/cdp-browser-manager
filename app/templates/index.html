API 密钥

            

                
                
                
服务端设置了 API_KEY 时，所有管理请求都需要它。密钥只保存在当前浏览器，远端主机的密钥由服务端配置，不会显示在这里。

            

            

                
                
            

        

    


    
    

        

            
远程接入

            

                
                
                
到目标主机的面板「远程」里生成接入令牌得到连接串，粘贴到这里即可接入。添加后可在「新建实例 → 目标主机」里选择它，直接远控那台主机的浏览器。

                
            

            

                
                
加载中…

            

            

                
                
                

                    
                    

                    
                

                

            

            
连接串 = 地址|令牌。令牌等同本机完整管理权限，只发给自己的其他主机；保存在服务端数据目录，重启不丢；吊销后旧连接串立即失效。若本机已设置 API_KEY，令牌与它等效。
